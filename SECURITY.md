# Security

> How to report a security problem in anything I make. Thanks for taking the time.

## Where to report

| Project | Report privately |
| --- | --- |
| Tierinator · tierinator.sayel.dev | [Report a vulnerability](https://github.com/blaziikun/tierinator/security/advisories/new) |
| UniverList · univerlist.sayel.dev | [Report a vulnerability](https://github.com/blaziikun/univerlist/security/advisories/new) |
| sayel.dev, or anything else | [Report a vulnerability](https://github.com/blaziikun/.github/security/advisories/new) |

Please don't open a public issue for a security problem.

## What helps

- What's affected (the address or file), steps to reproduce, and what an attacker could do with it.
- A proof of concept, if you have one.

## What to expect

- A reply within a week or two. These are spare-time projects.
- A fix as soon as it's practical, and credit in the advisory if you'd like it.
- No bug bounty. Automated scan output without steps to reproduce won't get a reply.

## Please don't

- Access, change or delete other people's data, or test against accounts that aren't yours.
- Run denial-of-service attacks or high-volume automated scans.

If you follow these rules in good faith, I won't take action against you.
